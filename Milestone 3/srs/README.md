## Final scope reconciliation, October 2

The final document has 25 functional and 6 non-functional requirements. It retains
all 12 BasicML operations and the GUI file/input/output/recovery workflow. Earlier
proposals for code editing/viewing, register displays, and step/resume controls
were not selected for Milestone 3. The milestone requests conversion of existing
functionality to a GUI, not additional core features. The vague resource-usage
requirement was dropped; recoverability now specifies reloading a program, and
response time specifies an already loaded instructor fixture on the tested desktop.
Original drafts remain unchanged. Final requirement IDs were renumbered sequentially.
